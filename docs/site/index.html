foxBMS POSIX documentation

The POSIX port runs foxBMS 2 v1.10.0 as a virtual ECU on Linux. A battery model sends simulated measurements over SocketCAN. Use the SIL environment to exercise BMS states, CAN interfaces and fault responses.

The engineering records include Automotive SPICE work products, ISO 26262 safety analyses and test specifications. The SIL evidence covers simulated behavior; target hardware and production safety validation are outside its scope.
